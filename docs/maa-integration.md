# Maa 集成说明

本仓库只提供本地化文本查询数据，不是可以直接加载的 MaaFramework Pipeline、卡牌目录
或视觉识别资源包。

## 适合的用途

- 根据 `CN_*` 文本键显示多语言卡牌名称。
- 根据 `SD_*` 文本键展示或检索技能描述。
- 为人工审核卡牌策略、关键词和翻译差异提供文本依据。
- 在本地构建精简、已审核的 Maa 卡牌目录。

## 不应直接推导的内容

- 文本 ID 不一定等于运行时卡牌 ID。
- 技能文本不能可靠给出当前战局的合法选择目标。
- 文本中出现“守护”“突进”或“疾驰”不一定表示该卡永久拥有该特性。
- 条件性获得、进化后状态、临时禁攻和多阶段选择必须由当前战局观察或人工规则处理。
- 本仓库没有卡图，不能直接提供 `TemplateMatch` 或 `FeatureMatch` 素材。

## 推荐接入方式

使用方应在本地把主数据中的文本键与卡牌 ID 显式关联，只选取实际卡组需要的文本，生成
一个独立、已审核的运行时目录。运行时目录应把文本当作显示和策略提示，而不是合法目标
或可执行状态的唯一来源。

实时对战流程仍需独立实现盘面观察、手牌识别、动作执行、选择阶段处理和状态变化验证。
这些实现及其视觉资源不属于本数据仓库。
